# WeatherMetricsWeb API

Weather Metrics Web API is a git repo for an ASP.NET CORE MVC RESTful Web Service which uses MS Entity Framework to perform CRUD operations on a SQL Server Database.

This ASP.NET CORE MVC RESTful Web Service has been deployed to an Azure App Service via an Azure DevOps CI/CD pipeline and currently accesses a Azure SQL Database.

This Web API Also Support ASP.NET CORE Application Logs which can be viewed in the App Service Monitoring Log Stream.  Simply enable App Services Logging in the App Service Monitoring Menu.
